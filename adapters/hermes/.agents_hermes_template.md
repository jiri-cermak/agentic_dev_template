## Local learning register

Store run observations in `learnings/`. Classify every observation as `core`, `adapter`, `project-specific`, or `historical`. Only `core` observations may be proposed for propagation into `CORE_PROTOCOL.md`.

Additionally, persist durable facts to Mnemosyne:
- Patterns → episodic memory
- Project facts → persona memory
- Ephemeral task state → working memory

## Operating rule

The core protocol defines the orchestration lifecycle. The Hermes overlay adds Hermes-specific capabilities. This adapter defines the project. If they appear to conflict, stop and resolve the ambiguity before delegation.
